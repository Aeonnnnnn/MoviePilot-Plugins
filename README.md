# 弹幕刮削定制版（DanmuCustom）

基于弹弹 play 平台生成弹幕字幕文件，在 MoviePilot 中实现弹幕播放。本插件是对原版 Danmu 的深度定制增强版，在刮削稳定性、媒体匹配、弹幕过滤与批量任务管理等方面做了大量重构与优化。

- 插件 ID：`DanmuCustom`
- 版本：v3.4.2
- 作者：Aeonnnnnn
- 适用系统：MoviePilot >= 2.12.0
- 标签：弹幕 / 字幕 / 刮削 / 过滤

## 功能

### 弹幕刮削核心
- 通过弹弹 play 平台 API 拉取弹幕，生成 ASS 字幕文件，播放器加载即可实现弹幕效果。
- **主备接口自动切换**：主接口异常时无缝降级到备用通道，显著提升长时间、大批量刮削任务的可用性。

### 媒体识别与匹配
- **TMDB 媒体识别**：文件浏览器内置 TMDB 按钮，流程为「文件名 → TMDB 搜索 → 弹弹 Play 匹配」，解决视频转码 / 压缩后文件 hash 失效导致无法匹配的问题。
- **手动番剧匹配**：支持目录级与文件级绑定 `animeId` + 集数偏移；目录级匹配向上递归 2 层，自动覆盖子目录。
- **双信号番剧根识别**：同时支持 `tvshow.nfo` 与 `Season` 子目录两种番剧根判定方式，兼容关闭 NFO 的场景。
- **智能搜索**：搜索关键词自动剥离集数、分辨率等噪声信息，提高匹配准确率；搜索接口命中配额限制时给出 429 提示并引导使用目录刮削。
- **批量分季匹配下载**：自动识别 `SeasonX` 子目录并独立匹配。

### 七阶段弹幕内容过滤系统
1. **模式屏蔽**：按弹幕显示模式（如顶部 / 底部 / 滚动）过滤。
2. **关键词 / 正则 / 组合规则屏蔽**：内置词库管理，支持分类关键词、正则表达式与组合规则。
3. **封禁用户与信用评分**：对低质量弹幕发送者扣分、封禁；信用分与封禁名单持久化，插件重启不丢失。
4. **相似弹幕去重**：采用双字 shingle 倒排 + 长度 / bigram 预筛，高效剔除重复弹幕。
5. **同屏密度删减**：限制同一时间轴上弹幕密度，避免画面过于拥挤。
6. **原生字幕合并**：将视频自带字幕与弹幕字幕智能合并。
7. **中文转换**：可选将弹幕中的非中文内容做中文转换处理。

### 批量与任务管理
- **后台 Worker 队列 + SQLite 持久化**：刮削任务由后台 worker 异步执行，任务状态写入 SQLite，重启不丢失、历史不归零。
- **优雅暂停 / 继续 / 取消**：全局与目录级刮削均可随时中断，进度不丢；支持暂停后继续、取消与清空。
- **智能跳过**：已刮削成功的文件夹通过 `.danmu.ass` + `config_hash` 双重校验智能跳过，避免重复处理；分季批量刮削自动跳过全部完成的子文件夹。
- **重试性能优化**：限制最大重试次数、设置重试列表容量上限与单次定时执行上限，防止批量刮削数千文件时任务无限膨胀。
- **文件浏览器状态可视化**：文件夹列表显示刮削状态（已刮削数 / 总数）及底层目录标识（含字幕文件）。

### Vue 前端界面
- 基于 Vue Federation 的独立前端，包含文件浏览器、配置面板、刮削历史等页面。
- 侧栏导航集成「刮削管理」「过滤管理」。
- 刮削任务控制栏（暂停 / 继续 / 取消）、历史弹窗（标题、总数、状态筛选、关闭）等交互细节持续优化。
